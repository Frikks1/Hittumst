# Hittumst brand

The speech-room mark combines two offset conversation marks: forest represents discretion, mint
represents openness, and lava is the warm conversational accent. The mark and wordmark are original
project assets and should retain generous clear space.

Primary UI colors are Forest `#10201B`, Mint `#78DFC1`, Lava `#D75B3D`, and Snow `#FCFBF7`.
Do not introduce yellow/black honeycomb treatments or reproduce another dating service's iconography.
