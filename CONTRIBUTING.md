# Contributing

Use Node.js 22+ and install from the repository root. Keep mobile, admin, shared contracts, and
database changes synchronized. Every database change needs a migration and policy tests; every new
user-facing string needs Icelandic and English translations.

Do not use real user data in seeds, screenshots, fixtures, or bug reports. Do not log coordinates,
message bodies, tokens, or report evidence. Changes to age gates, consent, location, blocking,
reporting, moderation, or deletion require an explicit abuse-case review.
