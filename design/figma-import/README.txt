Hittumst — editable Figma import

1. Open the new Figma file: https://www.figma.com/design/l7tCNhvM1Tx5YBWtnfrol0
2. In the Figma desktop app, open Plugins > Development > Import plugin from manifest.
3. Choose manifest.json from this folder and run Hittumst — editable current UI.

The plugin creates five editable reference frames based on the supplied screenshots:
Profile top, Profile sections, Messages, Create meetup (location step), Meetups.
Frame dimensions: 360 x 800 logical pixels. Screenshot dimensions: 576 x 1280.
Text, shapes, icons, image fills, colour variables and basic navigation are editable.
The forest/pink palette and Icelandic labels follow the supplied screenshots.
Portraits use the same public demo URLs as the app. Missing downloads leave coloured slots.
Icons are editable SVG approximations. OS chrome is illustrative.
This import has not been executed or visually checked in Figma because the Starter MCP tool quota is exhausted.
This is a reference reconstruction of the five supplied views, not a complete replica of all app states.

Responsive sizing:
Use a fixed 360 x 800 frame to match the reference, or 390 x 844 for a larger phone.
Use Auto Layout inside each frame. Keep the bottom navigation and profile actions fixed.
Let the middle content scroll vertically; do not shrink text to fit the whole form.
X/Y in Figma are canvas coordinates. W/H are frame dimensions.
